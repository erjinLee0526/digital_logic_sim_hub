# 连线规则 v6

> 图例：
> - `┌┐└┘─│` 芯片矩形边框
> - `●` 引脚（芯片边框外侧一格）
> - `←──` / `──→` 水平引出段（≥20px，一个格子，远离芯片）
> - `│` 竖向段
> - `┤├` 芯片左右边界

### 出口方向判断规则

```
引脚 X < 芯片中心 X  →  出口方向 = -1（左）
引脚 X ≥ 芯片中心 X  →  出口方向 = +1（右）
```

## 一、普通直连（无分支）

### 场景 A：同芯片同侧

#### A1. 两个左侧引脚（如 1A→1B）

```
                       ┌──────────┐
         ←─────────●1A─┤          │
         │             │ 74LS00   │
         │             │          │
         │             │          │
         ←─────────●1B─┤          │
                       └──────────┘

    ←── 水平引出（从引脚向左，≥20px）
    │   竖向段（芯片外侧，距芯片≥20px）
    ●   引脚（芯片左边缘外侧）
    ┤   芯片左边界
```

**算法：**
1. 两个引脚各自向外水平引出 20px（`exitMargin`，一个格子）
2. 竖向段 X 由 `_candidateColumns` 生成 —— 在芯片左侧外侧区域扫描 50 个候选位，选第一个全部 5 段无碰撞的
3. 到目标 Y 后水平折入引脚

#### A2. 两个右侧引脚

```
    ┌──────────┐
    │          ├─●11─────────→
    │ 74LS00   │             │
    │          │             │
    │          ├─●12─────────→
    └──────────┘
```

镜像：向右引出 → 竖向段在芯片右侧 → 向左折入。

---

### 场景 B：同芯片异侧（如 1A→8Y）

两个引脚在芯片一左一右，导线需要绕过芯片外侧（上方或下方）。

**算法（以绕上方为例）：**
1. 左引脚**向左**水平引出 20px（`exitMargin`，一个格子）
2. 比较左引脚 Y 到芯片上边和下边的距离，选**较短**的方向走
3. 沿短方向移动 Y，**超出芯片边缘 +20px**（`cornerMargin`，一个格子）
4. **向右**拐弯，移动 X 直到**芯片右侧 +20px**
5. 向上或下移动 Y，到与目标引脚相同的 Y 坐标
6. 最后**向左**水平折入目标引脚（从右侧进入）
7. （右引脚自身的引出线：向右引出20px，等步骤6的线来接）

**绕上方（距离短时）：**

```
       ←──────────────────────────────────────┐
       │                                      │
       │       ┌──────────────────────┐       │
       │       │                      │       │
       └───────┤       74LS00         ├───────┘
               │                      │
               └──────────────────────┘
               
         左引脚 1A                右引脚 8Y
       (向左引出)               (从右侧进入)
```

路径：1A → 左20px → 上超顶部+20px → 右到芯片右+20px → 下至8Y同高 → 左入8Y

**绕下方（距离短时）：**

```
               ┌──────────────────────┐
               │                      │
       ┌───────┤       74LS00         ├───────┐
       │       │                      │       │
       │       └──────────────────────┘       │
       │                                      │
       ←──────────────────────────────────────┘
       
         左引脚 1A                右引脚 8Y
       (向左引出)               (从右侧进入)
```

路径：1A → 左20px → 下超底部+20px → 右到芯片右+20px → 上至8Y同高 → 左入8Y

> **禁止导线经过芯片矩形内部。导线始终在芯片外侧走。**

### 场景 C：不同芯片之间

#### C1. 左芯片左侧引脚 → 右芯片左侧引脚

```
              ┌──────┐                  ┌──────┐
    ←────●1Y──┤      │                  │      ├──●1A────←
    │         │ 左   │                  │  右  │         │
    │         └──────┘                  └──────┘         │
    │                                                    │
    │           向下绕开芯片（或向上，选短的）               │
    └─── 右走到两芯片之间空白区 ────────────────────────────┘
         再向上到目标 Y，右折入引脚
```

**步骤：**
1. 两引脚都向左引出
2. 候选竖向列 X 在左侧外侧区域
3. 向下（或向上，选短的）走出芯片上下范围 + 额外间距
4. 向右走到两芯片之间的空白区
5. 向上走到目标 Y
6. 向右折入

#### C2. 左芯片左侧引脚 → 右芯片右侧引脚

```
              ┌──────┐                  ┌──────┐
    ←────●1Y──┤      │                  │      ├──●8Y────→
    │         │ 左   │                  │  右  │         │
    │         └──────┘                  └──────┘         │
    │                                                    │
    │           绕上方或下方（选短的）                       │
    └── 右走，超出右芯片右侧 ──────────────────────────────┘
        调 Y 到目标高度，左折入引脚
```

**步骤：**
1. 左引脚向左引出，右引脚向右引出
2. 选上下较短方向，Y 走出芯片范围 + 额外间距
3. X 走到右芯片整体右侧（超出芯片右边）
4. Y 走到目标高度
5. X 向左折入（从右侧进入右侧引脚）

#### C3. 左芯片右侧引脚 → 右芯片左侧引脚（面对面）

```
          ┌──────┐              ┌──────┐
          │      ├──●1Y    ●1A──┤      │
          │ 左   │    →    ←    │  右  │
          │      │              │      │
          └──────┘              └──────┘

               面对面，直接 L 形
```

**步骤：**
1. 左引脚向右引出，右引脚向左引出
2. 如 Y 不同，先调 Y
3. 直接 X 连接

> 最简单：两引脚面对面，中间无障碍。

#### C4. 左芯片右侧引脚 → 右芯片右侧引脚

```
          ┌──────┐                      ┌──────┐
          │      ├──●1Y────→            │      ├──●8Y────→
          │ 左   │         │            │  右  │         │
          └──────┘         │            └──────┘         │
                           │                             │
                           │    绕上方或下方（选短）        │
                           └─── 右走超出右芯片右侧 ────────┘
                                调 Y，左折入
```

**步骤：**
1. 两引脚都向右引出
2. 选上下较短方向，Y 走超出芯片范围 + 额外间距
3. X 走到右芯片整体右侧
4. Y 走到目标高度
5. X 向左折入

## 二、分支连线（T-Junction）

### 核心概念

当一个引脚已经有一条导线（**锚线**），又想从同一引脚连接第二条线时：

1. **锚线**（第一条线）保持不动，正常从引脚出发
2. **新线**（第二条+）从锚线路径的**竖向段**上分支出来
3. 分支处绘制圆形**连接点**（junction dot，半径 4.5px）

### 锚线竖向段

锚线路径中取最长的竖向段：

```
              ┌──────────┐
    ●1Y ←─────┤          │
    A         │ 74LS00   │
    │         │          │
    │  竖向段  │          │
    │         │          │
    B         │          │
    ●2A ←─────┤          │
              └──────────┘
    
    A = 竖向段顶部（上拐角，yMin）
    B = 竖向段底部（下拐角，yMax）
    │ = 竖向段（所有点 X 坐标相同）
```

### 分支点选择（三规则）

| 目标引脚 Y 位置 | 分支点 | 说明 |
|:--|:--|:--|
| 目标在 A **上方**（targetY < yMin） | `(seg.x, seg.yMin)` = A | 从顶部拐角出发 |
| 目标在 B **下方**（targetY > yMax） | `(seg.x, seg.yMax)` = B | 从底部拐角出发 |
| 目标在 A 和 B **之间** | `(seg.x, targetY)` | 取同 Y 坐标，直接水平连线 |

```
目标在 A 上方:          目标在 B 下方:          目标在 A B 之间:
                        
    ●目标                    │                      │
    │                       │                      │
    A                       A                      A
    │                       │                      │
    │                       │                   ●──┤ 分支点(同Y)
    │                       │                      │
    B                       B                      B
    │                       │                      │
    │                       ●目标                   ●目标
```

### 场景 D1：锚线和新线在同一侧

目标在 B 下方（如 1Y↔2A 锚线，2A 再连 2B）：

```
              ┌──────────┐
    ←──●1Y    │          │
    │         │ 74LS00   │
    │         │          │
    │         │          │
    B ──●2A   │          │
    │new      │          │
    └──●2B    │          │
              └──────────┘

    分支点 = B（竖向段底角）
    新线从 B 向下引出，向左折入 2B
```

目标在 A 上方 → 选 A，从 A 向上走。
目标在 A B 之间 → 取竖向段上同 Y 位置，直接水平折入。

### 场景 D2：左侧 A-B 竖向段，连接右侧 C

A、B 位于芯片左侧，通过芯片外侧的一段竖向连线（A-B 竖向段）连接；目标引脚 C 位于芯片右侧。新增连线从 A-B 竖向段上的某个位置分支，绕过芯片，最后从右侧水平进入 C。

- 原图 ①：分支点位于 **B 高度**，向下绕过芯片底部
- 原图 ②：分支点位于 **A 高度**，向上绕过芯片顶部
- 黑线、蓝线只是手绘中用来区分“已有路径”和“新增路径”的颜色，规则本身不应依赖颜色

#### D2-下：分支点在 B 高度，向下绕行到 C（对应原图 ①）

```
            ┌──────────────┐
      ┌─────┤ A            │
      │     │              │
      ●─────┤ B          C ├─────┐
      │     │              │     │
      │     └──────────────┘     │
      └──────────────────────────┘
```

路径顺序：

```
B 高度的分支点
 → 向下
 → 绕过芯片底部
 → 向右
 → 向上到 C 的高度
 → 从右侧水平进入 C
```

#### D2-上：分支点在 A 高度，向上绕行到 C（对应原图 ②）

```
      ┌──────────────────────────┐
      │     ┌──────────────┐     │
      ●─────┤ A          C ├─────┘
      │     │              │
      └─────┤ B            │
            └──────────────┘
```

路径顺序：

```
A 高度的分支点
 → 向上
 → 绕过芯片顶部
 → 向右
 → 向下到 C 的高度
 → 从右侧水平进入 C
```

#### 上下方向选择

D2-上和 D2-下都合法时，分别计算完整 Manhattan 路径长度：

- 上绕路径更短：选择 D2-上
- 下绕路径更短：选择 D2-下
- 长度相同：选择与已有导线、芯片障碍物冲突更少的一侧

### 场景 D3：右侧 A-B 竖向段，连接左侧 C（D2 的严格左右镜像）

D3 是 D2 的严格左右镜像，A/B/C 的相对拓扑不变：

- A、B 的竖向段位于芯片**右侧**
- C 位于芯片**左侧**
- 分支点在 B 高度时：向下绕过芯片底部，再从左侧水平进入 C
- 分支点在 A 高度时：向上绕过芯片顶部，再从左侧水平进入 C
- 上下方向选择只依据合法路径的总长度和冲突情况

#### D3-下：分支点在 B 高度，向下绕行到 C

```
            ┌──────────────┐
            │            A ├─────┐
            │              │     │
      ┌─────┤ C          B ├─────●
      │     │              │     │
      │     └──────────────┘     │
      └──────────────────────────┘
```

路径顺序：

```
B 高度的分支点
 → 向下
 → 绕过芯片底部
 → 向左
 → 向上到 C 的高度
 → 从左侧水平进入 C
```

#### D3-上：分支点在 A 高度，向上绕行到 C

```
      ┌──────────────────────────┐
      │     ┌──────────────┐     │
      └─────┤ C          A ├─────●
            │              │     │
            │            B ├─────┘
            └──────────────┘
```

路径顺序：

```
A 高度的分支点
 → 向上
 → 绕过芯片顶部
 → 向左
 → 向下到 C 的高度
 → 从左侧水平进入 C
```

共同规则：导线必须从芯片所在侧水平引出或引入，不得穿过芯片本体。

## 三、路由算法（Phase 1 + Phase 2）

### 整体流程

```
computeWireRoute(p1, p2, chip1, chip2, allChips, overrideStart?, overrideEnd?)
│
├─ overrideStart/overrideEnd 有值 → 试直接 L 形（仅分支点场景）
│
├─ Phase 1：列扫描
│   ├─ 生成候选竖向列 X 坐标 (50 个)
│   ├─ 每列试 5 段路径：引出 → 拐弯 → 竖向 → 拐弯 → 折入
│   └─ 全部 5 段无芯片碰撞 → 成功
│
└─ Phase 2：绕行
    ├─ 判断绕上 / 绕下（选距离短的）
    ├─ X 走到所有芯片外侧
    ├─ Y 走到 clearance 位置
    └─ X/Y 分别折入目标
```

### Phase 1：列扫描

```
候选列生成规则:
- 同侧 (dir1 == dir2): 从两引脚中更外侧开始，沿出口方向排 50 列
- 异侧 (dir1 ≠ dir2): 从两引脚中点开始，向两侧排 50 列
```

### Phase 2：绕行

```
如果 Phase 1 全部失败（芯片遮挡），走绕行：
1. 计算覆盖 Y 范围内所有芯片的 top/bottom
2. 选绕上方还是绕下方（引脚到 top/bottom 的距离和更小者胜）
3. 水平走到所有芯片外侧（X 方向）
4. 竖向走到 clearance 位置
5. 水平折入目标引脚
```

### 芯片避障

每个组件的碰撞检测矩形 = 可见矩形 + 水平各 20px（一个格子）扩张：

```
碰撞矩形 = 【组件 left - 20, top - 20, right + 20, bottom + 20】
```

检测线段的碰撞时，可以跳过起点/终点所在芯片（`skipChipId`），因为从自己芯片的引脚引出不算碰撞。

## 四、直接 L 形路径（分支点专用）

当 `overrideStart` 或 `overrideEnd` 不为 null 时（即从分支点出发），先尝试直接 L 形：

```
路径 A（竖向优先）: start → (start.x, end.y) → end
路径 B（水平优先）: start → (end.x, start.y) → end
```

两条路径都做芯片碰撞检测，任一条通过即可。

**进入方向检查**：如果终点在芯片的右侧引脚上，进入时必须是水平段从左到右，否则导线会穿过芯片：

```
entersFromCorrectSide: 检查拐角是否在引脚出口方向的正确一侧
  引脚在芯片左侧 → 拐角 X ≤ 引脚 X（从左侧进入）
  引脚在芯片右侧 → 拐角 X ≥ 引脚 X（从右侧进入）
```

## 五、特殊场景

### 同芯片引脚，直接 L 形被拦截

如果直接 L 形的水平段穿过芯片体，`_segHitsChip` 检测到碰撞 → 回退到 Phase 1 列扫描。

这防止了类似 1A→1B（同芯片左侧两个引脚）被错误地画成穿过芯片的直线。

### 反馈环路

同一芯片不同引脚可以互连（如前级输出接后级输入），走线规则同普通直连。

## 六、距离参数

| 参数 | 值 | 含义 |
|------|-----|------|
| `gridUnit` | 20px | 基础栅格；芯片中心、引脚、导线列、避障统一吸附 |
| `exitMargin` | 20px | 引脚水平引出距离（一个格子） |
| `cornerMargin` | 20px | 绕行时超出芯片上下边的距离（一个格子） |
| `chipExpand` / `wireClearance` | 20px | 所有组件避障外扩距离（一个格子） |
| `candidateStep` | 20px | 候选列之间的间距（一个格子） |
| `candidateCount` | 50 | 每方向候选列数量 |
| `branchDistance` | 20px | pinBranchOffset 固定偏移（fallback，一个格子） |
| `junctionDotRadius` | 4.5px | 连接点圆点半径 |
| `pinRadius` | 12px | 引脚命中检测半径 |
| `wireHitTolerance` | 10px | 导线命中检测容差 |

## 七、代码结构

### 顶层函数（`circuit_painter.dart`）

| 函数 | 作用 |
|------|------|
| `computeWireRoute(...)` | 核心路由：Phase 1 + Phase 2，供 painter / hit_test / 分支计算共用 |
| `computeWireBranchPoint(pinId, circuit, ...)` | 计算分支点位置 |
| `findVerticalSegment(path)` | 找路径中最长竖向段 |
| `branchPointOnSegment(seg, targetY)` | 在竖向段上按三规则选取分支点 |
| `pinBranchOffset(pinId, pinPos, circuit)` | 简单固定偏移分支点（fallback） |
| `exitDirection(pinPos, chip)` | 判断引脚出口方向（-1/+1） |

### 类

| 类 | 作用 |
|------|------|
| `VSegment` | 竖向段数据（x, yMin, yMax） |
| `CircuitPainter` | CustomPainter，渲染芯片、导线、连接点 |

### 渲染流程（`_drawWires`）

1. 遍历所有导线，按引脚分组（`wiresForPin`）
2. 对多线引脚，取其第一条线作为锚线（`anchorWire`）
3. 计算锚线的完整路径 → 提取最长竖向段（`anchorVSegs`）
4. 对每个多线引脚的后继线：
   - 用 `branchPointOnSegment(anchorVSeg, targetY)` 计算分支点
   - 传入 `computeWireRoute` 的 `overrideStart`/`overrideEnd`
5. 在分支点处绘制连接点（`_drawJunctionDots`）

### Ghost wire（预览线）

在 `circuit_canvas.dart` 中，当已选中引脚且有 ≥1 条导线时，ghost wire 起点使用 `computeWireBranchPoint(selectedPinId, circuit, requireMultipleWires: false)`。

### Hit test（点击检测）

在 `hit_test.dart` 中，使用与 painter 相同的逻辑计算导线路径，检测点击是否在路径附近。

## 九、制图规范对照与 v6 决策

本节记录“真实 DIP 实验箱拟真”与“通用电路原理图制图规范”的对照结论，以及 v6 阶段确认采用的规则。

### 1. 以真实 DIP 引脚排布为准

- 本项目是对电路实验箱的拟真，不是抽象原理图编辑器。
- 芯片按真实 DIP 引脚排布：1–7 在左、8–14 在右，VCC/GND 也按真实引脚号摆放。
- 不采用“输入在左、输出在右、电源在上、地在下”的抽象原理图符号规则。

### 2. 只吸收与连线制图相关的行业规则

适用并保留的行业规则：

- 正交走线，禁止斜线。
- 导线不得穿过元器件本体。
- 从引脚先直线引出，再拐弯。
- 连接点用实心圆点。
- 未连接交叉不画连接点；后续用半圆跳线表达。
- 避免四路交叉。
- 尽量减少导线交叉。
- 芯片、引脚、导线、文字统一对齐到栅格。

### 3. 网络标签与总线的定位

- 网络标签暂不作为隐藏电气连接使用，以保持“真实导线可见”的拟真性。
- 后续可作为信号注释/节点名称，帮助阅读电路，但不替代真实导线。
- 总线优先级较低，暂缓。

### 4. 半圆跳线

- 两条不同导线正交交叉且无电气连接时，使用半圆跳线表达“跨越”。
- 同一网络上的连接点、分支点、共享引脚端点不得画跳线。
- 默认规则：水平线在上，竖直线在下。
- 实现时需要先识别哪些交叉点属于同一网络，避免把连接点误画成跨越。

### 5. 位号与引脚号

- 引脚号是实际插线的主要依据，优先显示。
- 引脚功能名作为次级信息，可缩小显示、悬停显示或缩放分级显示。
- 普通芯片使用位号 `U1`、`U2` 等，区分同型号多个实例。
- INPUT 组件使用 `IN1`、`IN2` 等；LED 组件使用 `LED1`、`LED2` 等。
- INPUT/LED 名称必须稳定，不能依赖列表顺序临时生成，删除或重排后仍应保持一致。

### 6. 文字与标签不重叠

- 芯片型号、位号、引脚号、引脚功能名不得压住芯片本体或导线。
- 优先使用固定锚点，不做复杂动态避让。
- 缩小视图时隐藏次要文字，只保留位号和引脚号；放大后再显示完整信息。

### 7. 统一栅格与组件避障

- 基础栅格 `gridUnit = 20px`。
- 芯片中心、引脚位置、导线列、绕行距离、候选列均吸附到 20px 网格。
- 所有组件统一使用一个格子的避障外扩：

```text
routeObstacleRect = chip.rect.inflate(20px)
```

- 引出避障最小距离统一为一个格子：`exitMargin = 20px`。
- 绕行超出芯片上下边的距离统一为一个格子：`cornerMargin = 20px`。
- 点击命中检测仍使用可见的 `chip.rect`，不能使用 `routeObstacleRect`，避免误触组件。
- 普通 DIP 芯片、INPUT、LED 都遵守同一套避障规则；以后如需特殊组件，再单独 override。

## 十、栅格吸附与组件尺寸实现记录

本节记录已落地实现：芯片、INPUT、LED、导线全部对齐到 20px 网格。

### 统一栅格常量

在 `lib/models/circuit_grid.dart` 中定义：

```text
kGridUnit = 20.0
snapOffsetToGrid(Offset)
snapValueToGrid(double)
```

背景点阵、芯片位置、DIP 引脚间距、导线引出/绕行距离全部使用同一个 `kGridUnit`。

### 芯片与组件吸附

- `addChip` 在创建芯片前调用 `snapOffsetToGrid`。
- `moveChip` 在保存新位置前调用 `snapOffsetToGrid`。
- `loadCircuit` 加载旧文件时，把所有芯片位置吸附到网格，避免旧电路继续产生非网格导线。

因此无论是从芯片库添加、从 I/O 面板添加，还是画布拖动，芯片中心都会落在 20px 格点上。

### DIP 引脚生成规则

`ChipDefinition._computePinPositions()` 改为按网格生成：

```text
maxPin  = 最大引脚号
perSide = maxPin / 2
pitch   = kGridUnit
topY    = -(perSide - 1) * pitch / 2

左引脚 num = 1..perSide：
  x = -width / 2
  y = topY + pitch * (num - 1)

右引脚 num = maxPin..perSide+1：
  x = +width / 2
  y = topY + pitch * (maxPin - num)
```

### 74LS00 当前网格尺寸

```text
width  = 80   → 4 格
height = 160  → 8 格
```

对应坐标：

```text
芯片左右边缘：x = ±40
芯片上下边缘：y = ±80
左侧引脚 x = -40
右侧引脚 x = +40
引脚 Y 坐标：-60, -40, -20, 0, 20, 40, 60
```

顶部和底部各留 `20px`，即一个格子的边距。

### INPUT / LED 当前网格尺寸

```text
INPUT：80 × 80，输出引脚位于 (+40, 0)
LED：  80 × 80，输入引脚位于 (-40, 0)
```

两个组件尺寸均为 4 格 × 4 格，芯片中心吸附后，四边和单引脚也落在格点上。

### 导线路由网格化

以下参数全部改为一个格子：

| 参数 | 值 |
|---|---:|
| `exitMargin` | 20px |
| `cornerMargin` | 20px |
| 避障外扩 | 20px |
| `candidateStep` | 20px |
| `branchDistance` | 20px |

路由中的中点、异侧候选列中点、Phase 2 绕行中点，都使用 `snapValueToGrid` 吸附后再使用，避免出现 `-10`、`+10` 这类半格坐标。

### 命中检测边界

- 路由和导线避障使用 20px 膨胀后的避障矩形。
- 点击芯片/组件仍使用可见 `chip.rect`，不扩大命中范围，避免误触。
